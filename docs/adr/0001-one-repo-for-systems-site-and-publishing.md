# One repo for systems, site, and publishing

Game Systems, the Demo site, and the publishing tools live in one repo with three top-level folders: `systems/` (one folder per System, code and tests), `site/` (the GitHub Pages Demo site, also runnable locally), and `publish/` (video making and posting to websites). Keeping them together means one change can update a System, its Demo, and its Post at once. Separate repos would be three things to keep in sync for a solo project.
